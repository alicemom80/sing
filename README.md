# 씽씽 바깥 세상 (Outside World)

영어를 처음 만나는 한국 아이(만 3~5세)를 위한 씽씽 바깥 세상 영어 놀이 웹앱이에요. 무료이고 광고가 없어요.

- 단어 카드, 듣고 고르기, 풍선 터뜨리기, 짝 맞추기, 오엑스, 복권 긁기, 미로, 묻고 답하기
- 주제 6개(땅 위 탈것, 하늘·물 탈것, 하늘·날씨, 자연·식물, 직업, 동네 장소), 단어 120개. 5개씩 묶음, 틀려도 벌점 없음, 첫 시도에 맞히면 별
- 소리는 기기 내장 음성(speechSynthesis)을 써요
- 폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요 (PWA)
